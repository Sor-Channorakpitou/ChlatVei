## Ground rule for this phase

Nothing in these documents is a verified government fact. Where a fee, document, or processing time is mentioned, it serves only as an example of what a source contains and is marked **unverified**. Verified service data is produced in Phase 2 by collecting each official source into `data/raw/` and recording its provenance in `data/metadata/`.
