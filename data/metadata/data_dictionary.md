# Data Dictionary

All tabular files are UTF-8 CSV with a header row. Empty string means "no value".

## Folder layout

| Path | Contents | Mutable? |
|---|---|---|
| `data/raw/<source_id>/<YYYY-MM-DD>.<ext>` | Unmodified snapshots of official sources (HTML/PDF) | **Never edited.** New snapshots are added, old ones kept |
| `data/processed/text/<source_id>/<snapshot>.txt` | Text extracted from each raw snapshot | Regenerated by `pipelines/extract_text.py` |
| `data/processed/documents.csv` | One row per extracted snapshot | Regenerated |
| `data/processed/annotations/service_facts.csv` | Hand-labeled facts quoted from sources (gold set) | Edited by annotators only; fact IDs are permanent |
| `data/processed/field_coverage.csv` | Service × field coverage | Regenerated by `pipelines/coverage.py` |
| `data/metadata/*.csv` | Registries of services, sources, and collection runs | Curated (log is append-only) |

---

## `metadata/services.csv`: candidate MVP services

| Column | Type | Description |
|---|---|---|
| `service_slug` | string, PK | Stable identifier, `[a-z0-9_]+` |
| `name_en` | string | Working English name (not an official title) |
| `category` | enum | `identity`, `identity_travel`, `civil_status`, `transport`, `business`, `visa`, `local_administration` |
| `responsible_body` | string | Body expected to deliver the service (to be confirmed from sources) |
| `government_level` | enum | `national`, `district`, `commune` |
| `mvp_status` | enum | `candidate`, `included`, `dropped` |

Khmer service names are intentionally absent. They will be taken from the official Khmer sources during annotation rather than translated.

## `metadata/sources.csv`: source registry

| Column | Type | Description |
|---|---|---|
| `source_id` | string, PK | `S` + 3 digits |
| `url` | URL | Canonical URL collected |
| `source_name` | string | Human-readable title |
| `publisher` | string | Organization publishing the content |
| `source_type` | enum | `web_page`, `pdf`, `law_record` |
| `tier` | enum | `T1` official primary · `T2` official document via archive · `T3` secondary (leads only) |
| `language` | enum | Declared page language: `en`, `km`. Note that "en" pages may contain mostly Khmer (see Phase 2 report) |
| `notes` | string | Known caveats |

## `metadata/service_sources.csv`: service ↔ source (many-to-many)

| Column | Type | Description |
|---|---|---|
| `service_slug` | FK → services | |
| `source_id` | FK → sources | |
| `relevance` | enum | `primary` (states the service's requirements) · `supporting` (partial info, contacts, announcements) · `legal_basis` (law/prakas/sub-decree) · `context` (secondary background) |

## `metadata/collection_log.csv`: every collection attempt (append-only)

| Column | Type | Description |
|---|---|---|
| `source_id` | FK → sources | |
| `collected_at` | ISO-8601 UTC | Attempt time |
| `url` / `final_url` | URL | Requested URL / URL after redirects |
| `outcome` | enum | `new` · `changed` · `unchanged` · `blocked_robots` (robots.txt disallows or is unreachable) · `http_error` · `fetch_error` |
| `http_status` | int | HTTP status code |
| `content_type` | string | Response `Content-Type` |
| `bytes` | int | Response size |
| `sha256` | hex | Hash of the response body; the basis for change detection |
| `raw_path` | path | Snapshot written (empty if none) |
| `error` | string | Error message for failures |

## `processed/documents.csv`: extracted text per snapshot

| Column | Type | Description |
|---|---|---|
| `source_id`, `snapshot` | | Identifies the raw file |
| `method` | enum | `html` · `pdf_text` (embedded text layer) · `ocr` (Tesseract `khm+eng`, for scanned PDFs) |
| `pages` | int | Pages (1 for HTML) |
| `chars` | int | Extracted characters |
| `khmer_char_ratio` | float 0–1 | Share of non-space characters in the Khmer Unicode block (U+1780–U+17FF) |
| `text_path` | path | Extracted text file |

## `processed/annotations/service_facts.csv`: labeled facts (gold set)

One row = one atomic fact about one service, quoted from one source snapshot.

| Column | Type | Description |
|---|---|---|
| `fact_id` | string, PK | `F` + 4 digits. **Permanent**: never renumber; append new rows |
| `service_slug` | FK → services | |
| `source_id`, `snapshot` | FK → raw file | Exact snapshot the evidence comes from |
| `field` | enum | `eligibility`, `required_document`, `step`, `fee`, `processing_time`, `location`, `contact`, `condition`, `validity` |
| `value` | string | Annotator's plain-English normalization of the fact |
| `applies_to` | string | Scope, e.g. "Type A, foreigner" or "Motorcycles and tricycles" |
| `amount` | int | Fees only: amount in minor-unit-free integer |
| `currency` | enum | Fees only: `KHR`, `USD` |
| `status` | enum | `stated` (the source states it) · `not_stated` (the source was checked and is silent). This separates **unknown** from **none** |
| `evidence` | string | Verbatim quote from the snapshot's extracted text (whitespace-insensitive). **Required when `status = stated`**, and tested automatically |
| `notes` | string | Ambiguities, conflicts, language of the evidence |
| `annotated_at` | date | |
| `review_status` | enum | `PENDING` · `UNDER_REVIEW` · `VERIFIED` · `REJECTED` · `OUTDATED` |
| `reviewer`, `reviewed_at` | | Required for `VERIFIED` (tested) |

**Invariant:** nothing in this file is public information until an admin moves it to `VERIFIED` through the application's review workflow.

## `processed/field_coverage.csv`: service × field coverage

For each service: `<field>_status` ∈ {`stated`, `not_stated`, `unannotated`} and `<field>_count` (number of stated facts) for the core fields `eligibility`, `required_document`, `step`, `fee`, `processing_time`, `location`, `contact`; plus `completeness` = share of core fields stated (empty if unannotated).
